# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-03

### Added
- Completed Exploratory Data Analysis (EDA) notebook with histograms, correlation heatmaps, and outlier check plots.
- Added modular `data_preprocessing.py` script handling missing checks, weekend/weekday binary mapping, and feature separation.
- Implemented `train.py` pipeline fitting a Linear Regression model with MAE, MSE, RMSE, and $R^2$ evaluation scores.
- Implemented Streamlit web interface in `app.py` with custom developer styling, sidebar education elements, and a live equation solver.
- Initialized open-source files: LICENSE (MIT), .gitignore, CONTRIBUTING.md, and PROJECT_STRUCTURE.md.
- Added branding and pitch materials under `reports/branding_assets.md`.
