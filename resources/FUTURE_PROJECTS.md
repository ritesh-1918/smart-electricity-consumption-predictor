# Volterra: Recommended Next Projects

Now that you've built an explainable regression forecasting engine, here are three next projects you should build to expand your portfolio:

---

## 📈 Project 1: Time-Series Demand Forecasting (Advanced Regression)
*   **Goal**: Predict electricity demand over the next 30 days based on sequential historical telemetry (not just daily averages).
*   **Key Algorithms**: ARIMA, Prophet, or LSTM (Long Short-Term Memory) neural networks.
*   **Why it helps**: Introduces time-series concepts (seasonality, trends, lag features, and autocorrelation).

## 🩺 Project 2: Smart Grid Anomaly Detector (Classification)
*   **Goal**: Classify whether current grid loads indicate normal usage, peak overload threats, or grid outages.
*   **Key Algorithms**: Logistic Regression, Random Forest Classifier, or XGBoost.
*   **Why it helps**: Transitions you from regression (predicting continuous numbers) to classification (predicting classes/labels), introducing metrics like F1-Score and ROC-AUC.

## 🌡️ IoT Sensor Stream Processor (Real-Time Engineering)
*   **Goal**: Hook up live temperature and humidity metrics from an Arduino/Raspberry Pi DHT11 sensor to the Volterra model API to trigger active energy recommendations automatically.
*   **Key Tech**: FastAPI, InfluxDB, WebSockets, Raspberry Pi.
*   **Why it helps**: Introduces real-time streaming data ingestion and IoT integration, showcasing end-to-end full-stack capabilities.
