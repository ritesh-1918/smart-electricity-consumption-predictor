# Volterra: Curated Learning Resources

Here is a list of recommended free learning materials, books, and courses to expand your understanding of Machine Learning and Data Science:

---

## 📚 Free Books & Documentation

*   **Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow** (Aurélien Géron): The gold standard for practical ML implementation.
*   **Introduction to Statistical Learning (ISLR)** (James, Witten, Hastie, Tibshirani): The definitive reference for the theory behind regression, classification, and clustering. Free PDF available at [statlearning.com](https://www.statlearning.com/).
*   **Scikit-Learn Documentation User Guide**: Incredibly detailed explanations of algorithm mechanics. [scikit-learn.org](https://scikit-learn.org/stable/user_guide.html)
*   **Streamlit Documentation API Reference**: Guides on widgets, layouts, and state caching. [docs.streamlit.io](https://docs.streamlit.io/)

---

## 🎓 Recommended Online Courses (Free)

*   **Machine Learning Specialization** (Andrew Ng via Coursera / DeepLearning.AI): Excellent foundation for theoretical math, gradient descent, and cost minimization.
*   **Kaggle Learn**: Short, interactive coding tutorials for Python, Pandas, Data Visualization, and Intro to ML. [kaggle.com/learn](https://www.kaggle.com/learn)
*   **Fast.ai: Practical Deep Learning for Coders**: A top-down approach focusing on building models immediately before studying the math. [course.fast.ai](https://course.fast.ai/)
