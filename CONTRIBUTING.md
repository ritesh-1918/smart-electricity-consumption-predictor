# Contributing Guidelines

We welcome contributions to the Smart Electricity Consumption Predictor project! Whether you want to fix a bug, add a feature, or improve documentation, this guide will help you get started.

## How to Contribute

1. **Fork the Repository**: Create your own copy of this project on GitHub.
2. **Clone the Fork**: Clone the project locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/smart-electricity-consumption-predictor.git
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-awesome-feature
   ```
4. **Implement and Test**: Verify that scripts run without syntax errors and your modifications don't break existing features.
5. **Commit Changes**: Use clean, descriptive commit messages.
6. **Push and Pull Request**: Push changes to your fork and open a Pull Request against the main branch.

## Code Style

* **PEP 8**: Follow standard Python code style guidelines.
* **Docstrings**: Provide Google-style or NumPy-style docstrings for functions.
* **Comments**: Ensure code is documented clearly since this repo serves as an educational workshop baseline.
